# Reycademy

**Free cybersecurity learning in Filipino.**

Reycademy is a cybersecurity learning website built for Filipinos who want to learn security concepts in a simpler and more familiar language. The project focuses on making cybersecurity more approachable through Filipino/Tagalog content and beginner-friendly explanations.

Welcome to version 0.4.0 of Reycademy!

Reycademy is a free IT learning site made for Filipinos. It offers Tagalog video lessons and hands-on training, designed to help beginners understand IT.

## Security

Security is also part of the project itself. Reycademy's backend includes several security controls, such as:

* Customized security headers with Helmet
* Content Security Policy (CSP)
* HSTS and other browser security headers
* Secure CORS configuration
* Rate limiting
* Password hashing
* Secure cookies
* Environment variables for sensitive configuration
* Page-specific cache controls

The deployed backend also receives an **A+ rating from SecurityHeaders.com**.

---

## Project Purpose

I built Reycademy because I wanted to create a place where Filipinos can explore cybersecurity without having to start with overly technical explanations or English-heavy material.

It also became one of my projects for learning **web development and web security**, giving me a place to experiment with backend security and understand how real web applications are put together.
